### A declared adaptation, not a silent substitution

The first report recommends selecting extreme-decile facets and omitting middling values. That recommendation also assumes the model's default behavior correctly represents the population midpoint, which the supplied material does not establish.

The compiler therefore prioritizes extreme-decile facets, up to eight. If none exist, it retains up to four moderately distinctive facets with **moderate wording**. A balanced profile receives a short explicit balanced/context-sensitive description. This avoids turning the earlier moderate profile into an empty personality prompt. The thresholds and templates are engineering choices requiring later calibration. There is no claim that raw numerical prompts are mathematically incapable of influencing an LLM.
