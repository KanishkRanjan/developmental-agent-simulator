# Archive

`work-scripts/` holds one-off scripts from earlier phases: preparing live fixtures, finalizing evidence, probing Graphiti restarts and regenerating handoff documents. They are kept so the provenance of the recorded runs in `runs/` stays inspectable.

They target the pre-restructure layout (`outputs/agent_engine/`, flat imports, original machine paths) and are not runnable as-is. Don't use them to regenerate documents; the docs are now maintained directly.
