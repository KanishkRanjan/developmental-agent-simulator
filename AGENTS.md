# Continuing this project

Before making implementation changes or reporting completion, read:

1. `outputs/START_HERE.md` — continuation guide and user decisions.
2. `outputs/agent_engine/BUILD_STATE.md` — latest verified build state.
3. `outputs/agent_engine/source-to-code-audit.md` — authoritative source fidelity and missing mechanisms.
4. `outputs/agent_engine/sources/README.md` — preserved reports, searchable text and mechanism references.
5. `outputs/agent_engine/development-notes.md` — latest developmental mechanisms, equations, checks and explicit limits.
6. `outputs/agent_engine/RESUME.md` — current connection status, saved checkpoints and continuation commands.
7. `outputs/agent_engine/integrated-build-notes.md` — latest cognition, history, planning and world policies, assumptions and source-version boundaries.

Use the latest audit over older milestone claims. Historical successful runs do not establish full design coverage or scientific validity. Inspect the relevant implementation before changing it; these documents reduce rediscovery, not the need to verify code.

When work changes the implementation or its verified status, update the build state and relevant audit entries before handing off. Keep user-facing deliverables in `outputs/` and temporary work in `work/`.
