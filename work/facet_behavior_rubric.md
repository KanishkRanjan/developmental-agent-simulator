# Prespecified coding rubric for blind pilot

For each open response, score the behavior of the *target facet* in that scenario: `high`, `low`, or `mixed/unclear`. Do not infer the profile from wording such as "I am introverted"; code only the chosen action or concrete plan. A response can be mixed when it clearly contains both action types. This rubric was written while generation was still running and before opening the blinded transcript.

- **E2 Gregariousness** (scenarios 0–1): `high` if the agent initiates conversations with several people or moves among groups. `low` if it stays alone, watches, or limits itself to one familiar/small conversation. Both patterns = `mixed`.
- **E3 Assertiveness** (scenarios 2–3): `high` if it clearly voices the concern or preference and advocates for it. `low` if it stays silent, waits for someone else, or yields without stating a preference. Tentative mention with immediate yielding = `mixed`.
- **C2 Orderliness** (scenarios 0–1): `high` if it sorts, labels, or arranges materials/notes before proceeding. `low` if it begins ad hoc without organizing. Minor preparation alongside immediate action = `mixed`.
- **C5 Self-discipline** (scenarios 2–3): `high` if it commits to a concrete way to continue or practices despite boredom. `low` if it postpones, skips, or only acts if motivation returns. A vague intention without action = `mixed`.
- **O1 Imagination** (scenarios 0–1): `high` if it invents an unusual/speculative world, place, or premise. `low` if it relies on a familiar realistic setting. No concrete content = `mixed`.
- **O4 Adventurousness** (scenarios 2–3): `high` if it chooses the unfamiliar activity/route. `low` if it chooses the familiar option. A purely conditional answer = `mixed`.

The paired comparison is directional. For a high target facet, a `high` action counts as concordant; for a low target facet, a `low` action counts as concordant. `mixed` counts as neither. Domain-only prompts are an identical-text control across paired profiles and should give identical responses at temperature zero.
